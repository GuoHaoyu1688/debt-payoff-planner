# Changelog

## 0.1.0

- Added six local debt models, nominal daily/annual rate conversion, Decimal fee IRR, fixed installments, equal principal, and maturity balloons.
- Added snowball, avalanche, custom, and minimum-only strategies; replacement monthly budgets; bounded shortfall/horizon failures; and one-time extra-payment comparisons.
- Added an append-only actual payment journal, explicit statement-charge overrides, retry keys, current balance updates, saved-plan progress, and upcoming minimum reminders.
- Added transactional JSON/CSV snapshots, dated SQLite backups, Markdown comparison reports with local balance/stacked charts, a responsive offline dashboard, CLI, and official MCP stdio tools.
- Added fictional examples, independent arithmetic and comparison-snapshot tests, English agent documentation, and Ubuntu Python 3.11/3.12 CI.
